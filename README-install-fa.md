# راهنمای نصب و تحویل سایت بانی‌پت

این یه سایت کامل PHP ـه که روی هر هاست ایرانی با سی‌پنل یا دایرکت‌ادمین بالا میاد.
هیچ ابزار جانبی، هیچ نصب پیچیده‌ای لازم نداره.

## ساختار سایت (سه لایه)

```
لایه ۱ — خانواده حیوون        خرگوش، گربه، سگ، پرنده، جونده، آبزی
  ├── سرپرستی همون خانواده     adopt.php?pet=...
  ├── لوازم همون خانواده       shop.php?pet=...
  └── مقاله‌های همون خانواده

لایه ۲ — دسته لوازم           غذا، بهداشت، خاک، لانه، حمل، بازی،
                               ظرف، درمان، قلاده، آکواریوم
  └── ترکیب دو فیلتر           shop.php?pet=gorbe&cat=ghaza

لایه ۳ — صفحه نهایی           product.php (محصول)  |  animal.php (حیوون)
```

صفحه‌های ثابت: درباره ما، پرسش‌های پرتکرار، تماس، مجله، سبد، تکمیل خرید، ورود، ثبت‌نام، حساب کاربری.

---

## ۱) چی لازمه

- هاست لینوکس با **PHP نسخه ۷.۴ یا بالاتر** (اکثر هاست‌های ایرانی PHP 8 دارن)
- افزونه‌های `pdo_sqlite` یا `pdo_mysql` — هر کدوم باشه کافیه
- یه دامنه، و بعداً SSL رایگان (توی سی‌پنل بخش SSL/TLS Status)

---

## ۲) دیپلوی روی هاست نت آرام (قدم به قدم)

نت آرام هم سی‌پنل داره هم دایرکت‌ادمین. هر دو رو نوشتم؛ فقط اون بخشی رو بخون که
پنل خودت همونه (توی ایمیل تحویل هاست نوشته شده کدومه).

### قدم ۱ — قبل از هر کاری، نسخه PHP رو چک کن
وارد پنل شو و دنبال گزینه **Select PHP Version** (سی‌پنل) یا
**Select PHP Version / PHP Selector** (دایرکت‌ادمین) بگرد.
نسخه رو روی **۸.۱ یا بالاتر** بذار. بعد مطمئن شو این دو افزونه تیک خورده باشن:
`pdo_sqlite` و `pdo_mysql`. معمولاً از قبل فعالن.

### قدم ۲ — آپلود فایل‌ها
**سی‌پنل:** File Manager → وارد پوشه `public_html` شو → دکمه Upload →
فایل `bunnypet-site.zip` رو آپلود کن → بعد از آپلود روش راست‌کلیک کن و **Extract** بزن.
حالا یه پوشه به اسم `bunnypet` ساخته می‌شه؛ **وارد اون پوشه شو**، همه فایل‌ها رو انتخاب کن،
Move بزن و ببرشون توی `public_html`. بعد پوشه خالی `bunnypet` رو پاک کن.

**دایرکت‌ادمین:** System Info & Files → File Manager → پوشه `public_html` →
Upload files → فایل zip رو بذار → روی فایل کلیک کن و **Extract** بزن → مثل بالا
محتویات پوشه `bunnypet` رو بکش بیرون توی `public_html`.

مهم: باید `index.php` مستقیم داخل `public_html` باشه، نه داخل یه پوشه دیگه.

### قدم ۳ — دسترسی پوشه data
توی فایل‌منیجر روی پوشه `data` راست‌کلیک کن → Permissions → عدد **۷۵۵** بذار
(اگه موقع نصب خطای نوشتن گرفتی، ۷۷۷ بذار و بعد از نصب برگردون روی ۷۵۵).

### قدم ۴ — نصب
توی مرورگر برو به `https://دامنه‌ات/install.php`.
صفحه سبز میاد با شماره و رمز مدیر. **همون لحظه یادداشتش کن.**
بعدش برگرد توی فایل‌منیجر و فایل `install.php` رو **پاک کن**.

### قدم ۵ — SSL رایگان
**سی‌پنل:** SSL/TLS Status → دکمه Run AutoSSL.
**دایرکت‌ادمین:** SSL Certificates → گزینه Free & automatic certificate from Let's Encrypt → Save.
بعد از اینکه قفل سبز اومد، توی `inc/config.php` این دو خط رو درست کن:
```php
'force_https' => true,
```
و توی `.htaccess` سه خط آخر (RewriteCond مربوط به HTTPS) رو از حالت توضیح دربیار.

### قدم ۶ — اگه آدرس‌های تمیز کار نکرد
اگه صفحه اصلی باز شد ولی مثلاً `/maghale/...` خطای 404 داد، یعنی `mod_rewrite`
روی اون سرور فعال نیست. یه تیکت به پشتیبانی نت آرام بزن و بگو «لطفاً mod_rewrite
روی هاستم فعال بشه». تا وقتی درست بشه، توی `inc/config.php` بذار:
```php
'pretty_urls' => false,
```
سایت کامل کار می‌کنه، فقط آدرس‌ها ساده‌تر می‌شن. هیچ لینکی نمی‌شکنه.

### قدم ۷ — معرفی به گوگل
برو به Google Search Console، دامنه رو اضافه کن، و توی بخش Sitemaps این آدرس رو بده:
`https://دامنه‌ات/sitemap.xml`

### قدم ۸ — قبل از تحویل به مشتری
- `install.php` پاک شده باشه
- رمز مدیر عوض شده باشه
- توی `inc/config.php` تلفن، نشانی، اینستاگرام و کد اینماد پر شده باشه
- یه خرید آزمایشی کامل بزن و ببین رسید درست میاد

## ۲ب) آپلود روی هر هاست دیگه (خلاصه)

۱. کل محتویات پوشه `bunnypet` رو با فایل‌منیجر سی‌پنل یا FTP بریز داخل `public_html`
(دقت کن خود پوشه رو نریزی تو، محتویاتش رو بریز)
۲. مرورگر رو باز کن و برو به `https://دامنه‌ات/install.php`
۳. یه صفحه سبز می‌بینی با شماره و رمز مدیر — **همون لحظه یادداشتش کن**
۴. فایل `install.php` رو از روی هاست **پاک کن**
۵. برو به `https://دامنه‌ات` — سایت آماده‌ست

همین. دیتابیس خودش ساخته می‌شه، ۶ خانواده، ۱۰ دسته لوازم، ۲۴ محصول، ۸ حیوون آماده سرپرستی و ۷ مقاله از قبل داخلشه.

## ۳) ورود به پنل مدیریت

`https://دامنه‌ات/login.php` → با شماره و رمزی که موقع نصب دادیم وارد شو.
بعد از ورود خودش می‌بردت به پنل. **اولین کار: از بخش حساب من، رمز رو عوض کن.**

توی پنل این‌ها رو داری:

| بخش | چی کار می‌کنه |
|---|---|
| خلاصه | تعداد سفارش، کاربر، حیوون، درخواست سرپرستی و مجموع فروش |
| محصول‌ها | افزودن، ویرایش و حذف محصول (قیمت، دسته، خانواده حیوون، موجودی) |
| حیوون‌ها | پرونده حیوون‌های آماده سرپرستی؛ اسم، نژاد، سن، ارزش سرپرستی، وضعیت |
| مقاله‌ها | نوشتن و ویرایش مقاله مجله |
| سفارش‌ها | دیدن سفارش‌ها و تغییر وضعیتشون |
| درخواست سرپرستی | کسایی که فرم سرپرستی رو پر کردن، با وضعیت پیگیری |
| درخواست مشاوره | شماره‌هایی که از فرم مشاوره و تماس اومده |
| کاربرها | لیست اعضای سایت |

## ۴) جاهایی که کارفرما باید اطلاعات خودش رو بذاره

همه‌ی این‌ها توی یک فایل جمع شده: **`inc/config.php`**

- اسم فروشگاه، شعار، تلفن، موبایل، نشانی، ایمیل، اینستاگرام
- **کد نماد اعتماد الکترونیکی (اینماد)**: کد HTML رو از پنل اینماد کپی کن و بذار توی `enamad_code`.
  تا وقتی خالیه، توی فوتر یه جای خالی با نوشته «در حال دریافت» نشون داده می‌شه
- **نشان ساماندهی**: همون کار، توی `samandehi_code`
- هزینه ارسال و سقف ارسال رایگان
- درگاه‌های پرداخت

باقی اطلاعات (محصول، قیمت، مقاله) همه از پنل مدیریت عوض می‌شه، نه از کد.

## ۵) درگاه پرداخت

الان سایت توی **حالت آزمایشی** (`sandbox => true`) ـه؛ یعنی مسیر خرید کامل کار می‌کنه
ولی هیچ پولی جابه‌جا نمی‌شه. برای فعال کردن پرداخت واقعی:

۱. مرچنت‌کد زرین‌پال رو بگیر (برای گرفتنش شخصیت حقوقی یا حقیقی ثبت‌شده لازمه)
۲. توی `inc/config.php` بذارش توی `gateways → zarinpal → merchant`
۳. `'sandbox' => false` کن
۴. تمام

درگاه‌های دیگه (آیدی‌پی، نکست‌پی) هم از قبل کدشون نوشته شده — فقط `enabled` رو true کن
و کلیدش رو بذار. کارت به کارت و پرداخت در محل هم فعالن و نیازی به درگاه ندارن.

**نکته مهم:** مبلغ تراکنش همیشه از دیتابیس خونده می‌شه، نه از چیزی که از مرورگر میاد.
یعنی کسی نمی‌تونه با دستکاری آدرس، مبلغ رو کم کنه.

## ۶) دیتابیس

پیش‌فرض روی **SQLite** ـه که هیچ تنظیماتی نمی‌خواد و برای نمونه‌ی کارفرما عالیه.
وقتی سایت واقعاً راه افتاد و ترافیک گرفت، بهتره بری روی MySQL:

۱. توی سی‌پنل یه دیتابیس و یوزر بساز
۲. توی `inc/config.php` بخش `db` رو این‌طوری کن:

```php
'driver' => 'mysql',
'host'   => 'localhost',
'name'   => 'اسم_دیتابیس',
'user'   => 'یوزر',
'pass'   => 'رمز',
```

۳. یک بار دیگه `install.php` رو آپلود کن، اجراش کن، دوباره پاکش کن

جدول‌ها: `users` (اعضا)، `pets` (خانواده حیوون)، `categories` (دسته لوازم)،
`products` (محصول)، `animals` (حیوون آماده سرپرستی)، `adoptions` (درخواست سرپرستی)،
`orders` و `order_items` (سفارش)، `articles` (مقاله)، `leads` (درخواست مشاوره و تماس).

## ۷) چه کارهایی برای امنیت انجام شده

- همه کوئری‌ها با **Prepared Statement** — تزریق SQL ممکن نیست
- رمزها با `password_hash` ذخیره می‌شن، نه متن ساده
- **توکن CSRF** روی همه فرم‌ها
- کوکی نشست: `HttpOnly` + `SameSite=Lax` + `Secure` روی HTTPS
- بازتولید شناسه نشست بعد از ورود (جلوگیری از Session Fixation)
- **محدودیت تلاش ورود**: ۶ بار اشتباه = ۱۵ دقیقه قفل
- همه خروجی‌ها با `htmlspecialchars` فرار داده می‌شن — حمله XSS بسته‌ست
- هدرهای امنیتی: CSP، X-Frame-Options، nosniff، Referrer-Policy
- پوشه‌های `inc/` و `data/` از بیرون کامل بسته‌ان
- تأیید پرداخت سمت سرور انجام می‌شه، نه سمت مرورگر

**بعد از نصب SSL** این دو کار رو بکن:
- `'force_https' => true` توی config
- توی `.htaccess` خط `Strict-Transport-Security` و سه خط `RewriteRule` مربوط به https رو از حالت توضیح دربیار

## ۱۰) راهنمای نگهداری (۳۱ بخش)

صفحه `/rahnama/khargoosh` یه راهنمای بلند ۳۱ بخشیه. هر بخش سه تا چیز داره که از پنل
مدیریت عوض می‌شن: متن، عکس، ویدیو.

- **عکس‌ها** رو توی پوشه `assets/img/guide/` آپلود کن و اسم فایل رو توی پنل بنویس.
  فهرست کامل اسم فایل‌ها و اندازه‌شون توی فایل `IMAGES-guide-fa.md` هست.
- **ویدیو** می‌تونه آپارات، یوتیوب یا فایل mp4 باشه. لینک معمولی رو بذار، خودش تبدیل می‌شه.
  برای مخاطب ایرانی آپارات بهتره چون یوتیوب بدون فیلترشکن باز نمی‌شه.
- تا وقتی عکس آپلود نشده، یه قاب پاستلی با شماره بخش نشون داده می‌شه. زشت نیست،
  ولی سایت با عکس واقعی خیلی حرفه‌ای‌تر می‌شه.

**نکته کپی‌رایت:** عکس‌های این صفحه باید یا مال خودتون باشه یا از بانک‌های عکس با

| صفحه | آدرس |
|---|---|

چیزهایی که برای سئو انجام شده:

- عنوان و توضیح متای جدا برای هر صفحه
- تگ canonical روی همه صفحه‌ها (جلوی محتوای تکراری رو می‌گیره)
- تگ‌های اشتراک‌گذاری، پس لینک توی واتساپ و تلگرام با عکس و عنوان درست نشون داده می‌شه
- داده ساختاریافته: مقاله به‌صورت Article، محصول به‌صورت Product با قیمت و موجودی، صفحه اصلی به‌صورت PetStore
- نقشه سایت خودکار روی `/sitemap.xml` که خودش از دیتابیس پر می‌شه — محصول جدید که اضافه کنی، خودکار میاد توش
- فایل robots که صفحه‌های سبد و پرداخت و پنل رو از دسترس گوگل خارج می‌کنه

## ۱۲) چرا «سرپرستی» و «ارزش» به جای «خرید» و «قیمت»

برای حیوون زنده، همه‌جای سایت نوشته شده «سرپرستی» و «ارزش سرپرستی»، و به جای دکمه خرید
نوشته «آشنا شو» و «درخواست سرپرستی». دلیلش این نیست که فقط قشنگ‌تره؛ این کار سه تا فایده عملی داره:

۱. مسیر فروش حیوون رو از مسیر سبد خرید جدا می‌کنه، پس هیچ‌وقت حیوون زنده توی سبد و پست قرار نمی‌گیره
۲. انتظار مشتری رو درست تنظیم می‌کنه: بعد از فرم، تماس و گفت‌وگو میاد، نه تحویل فوری
۳. از نظر تبلیغاتی و قانونی، جای امن‌تریه

ولی برای لوازم (غذا، شامپو، قفس) همون «خرید» و «قیمت» مونده، چون اونجا واقعاً خریده و
عوض کردن کلمه‌ش فقط مشتری رو گیج می‌کنه و به سبد خرید ضربه می‌زنه. اگه کارفرما اصرار داشت
که همه‌جا عوض بشه، توی فایل‌های `shop.php`، `product.php` و `index.php` قابل تغییره.
