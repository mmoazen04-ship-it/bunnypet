# بانی‌پت | Bunnypet

سایت کامل پت‌شاپ بانی‌پت — فروشگاه لوازم حیوانات خانگی، سرپرستی حیوان، مجله و راهنمای نگهداری.

نوشته‌شده با PHP و بدون هیچ وابستگی بیرونی. روی هر هاست اشتراکی ایرانی با سی‌پنل یا دایرکت‌ادمین بالا میاد.

---

## راه‌اندازی سریع

۱. محتویات ریپازیتوری رو بریز توی `public_html` هاست
۲. توی مرورگر برو به `https://دامنه‌ات/install.php`
۳. شماره و رمز مدیر رو یادداشت کن
۴. فایل `install.php` رو پاک کن

راهنمای کامل و قدم‌به‌قدم (شامل دیپلوی روی نت آرام): [`README-install-fa.md`](README-install-fa.md)

---

## چی توش هست

| بخش | توضیح |
|---|---|
| ساختار سه‌لایه | خانواده حیوون ← دسته لوازم ← محصول یا حیوون |
| فروشگاه | ۱۰ دسته لوازم، ۲۴ محصول نمونه، فیلتر دوگانه |
| سرپرستی | پرونده حیوون‌ها با «ارزش سرپرستی»، فرم درخواست، مراحل چهارگانه |
| راهنمای نگهداری | ۳۱ بخش، هر کدوم صفحه مستقل با جای عکس و ویدیو |
| مجله | ۷ مقاله |
| حساب کاربری | ثبت‌نام، ورود، تاریخچه سفارش، تغییر رمز |
| پرداخت | زرین‌پال، آیدی‌پی، نکست‌پی، کارت به کارت، پرداخت در محل |
| پنل مدیریت | محصول، حیوون، مقاله، راهنما، سفارش، درخواست سرپرستی، کاربر |
| سئو | آدرس تمیز، نقشه سایت خودکار، داده ساختاریافته، تگ اشتراک‌گذاری |

---

## نیازمندی‌ها

- PHP نسخه ۷.۴ یا بالاتر (۸.۱ پیشنهاد می‌شه)
- یکی از `pdo_sqlite` یا `pdo_mysql`
- `mod_rewrite` برای آدرس‌های تمیز (اختیاری — بدونش هم کار می‌کنه)

---

## ساختار پوشه‌ها

```
inc/          هسته: تنظیمات، دیتابیس، توابع، هدر، فوتر، درگاه پرداخت
admin/        پنل مدیریت
assets/       فونت، عکس، استایل، اسکریپت
data/         دیتابیس SQLite (توی گیت نمی‌ره)
*.php         صفحه‌های سایت
```

---

## تنظیمات

همه چیزی که باید عوض بشه توی یک فایله: [`inc/config.php`](inc/config.php)

اسم فروشگاه، تلفن، نشانی، کد نماد اعتماد الکترونیکی، مرچنت درگاه پرداخت، هزینه ارسال و نوع دیتابیس.

بقیه محتوا (محصول، حیوون، مقاله، راهنما) از پنل مدیریت عوض می‌شه، نه از کد.

---

## امنیت

- همه کوئری‌ها با Prepared Statement
- رمزها با `password_hash`
- توکن CSRF روی همه فرم‌ها
- محدودیت تلاش ورود
- هدرهای CSP، X-Frame-Options، nosniff
- پوشه‌های `inc/` و `data/` از بیرون بسته
- تأیید پرداخت سمت سرور، مبلغ همیشه از دیتابیس

⚠️ قبل از انتشار عمومی: مطمئن شو `install.php` پاک شده و رمز مدیر عوض شده.
